# Наш простір

Спільний застосунок для двох: лічильник днів разом, список покупок, справи з розподілом, ідеї побачень із жеребом.
Працює в браузері телефона, дані синхронізуються між двома пристроями через Supabase.

## Як це влаштовано

- `index.html` — увесь застосунок (одна сторінка, без збірки).
- `supabase/schema.sql` — таблиці, правила доступу і функції для бази. Виконується один раз у Supabase, розділ SQL Editor.
- `manifest.webmanifest`, `icons/` — іконка для головного екрана телефона.

Ключ у `index.html` публічний (publishable). Дані захищені правилами в базі: бачити й змінювати записи можуть тільки учасники простору, який створено за кодом.

## Запуск

1. У Supabase виконати `supabase/schema.sql`.
2. Увімкнути Authentication, Sign In / Providers, Anonymous sign-ins.
3. У GitHub: Settings, Pages, Branch `main`, папка `/ (root)`.
4. Відкрити `https://<імʼя>.github.io/nash-prostir/`.
